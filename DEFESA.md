# Relatório - Como se defender de Phishing

## O que eu aprendi neste desafio
Phishing é quando alguém cria uma página ou mensagem falsa
se passando por uma empresa verdadeira para enganar a pessoa
e roubar dados como senha, CPF ou dados do cartão.

O objetivo deste estudo foi entender como o golpe funciona
para saber como identificar e se defender dele.

## Como identificar um golpe de Phishing

1. **Olhe o link com calma**
   Se o link não for o oficial da empresa, desconfie.
   Exemplo: o site oficial é `banco.com.br`, o falso pode ser `banco-seguro.com` ou `banco.com.br.login.com`

2. **Desconfie de urgência**
   Mensagem falando "SUA CONTA VAI SER BLOQUEADA AGORA, CLIQUE AQUI!"
   é quase sempre golpe. Banco de verdade não pressiona assim.

3. **Verifique o remetente**
   Veja o e-mail completo de quem mandou, não só o nome.
   Se for um e-mail estranho, não clique.

4. **Não baixe anexo desconhecido**
   Arquivo .exe, .zip, .apk pode ser vírus.

5. **Nunca digite senha por link de WhatsApp ou e-mail**
   Sempre entre digitando o endereço oficial no navegador.

## O que fazer se cair no golpe

1. Trocar a senha na hora pelo site oficial
2. Ativar a verificação em duas etapas
3. Avisar o banco ou a empresa
4. Avisar os contatos, porque o golpista pode usar sua conta para enganar outros

## Conclusão
Depois desse desafio, aprendi que a melhor defesa não é só antivírus,
é prestar atenção no link, no remetente e não ter pressa para clicar.
